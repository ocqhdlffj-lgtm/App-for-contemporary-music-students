# 닮은꼴 스타일 — 닮은 연예인 & 베스트 스타일링

얼굴 특징으로 **동물상**과 **닮은꼴 연예인 TOP 3**를 찾고, 그 결과에 맞춰
**헤어·메이크업(그루밍)·패션·퍼스널컬러 팔레트·안경/액세서리**를 함께
추천하는 앱. 루트의 입시 앱과는 코드를 공유하지 않는 별도 PWA다
(테스트 러너 `tests/runner.js`만 같이 쓴다).

## 실행

빌드 도구가 필요 없다. `lookalike/index.html`을 브라우저에서 열면 된다.
GitHub Pages에서는 `<사이트 주소>/lookalike/`로 열리고 홈 화면에 설치할 수 있다.

- **직접 골라서 찾기**: 5문항(얼굴형·눈꼬리·눈 모양·눈 크기·입술) — 오프라인에서도 완전히 동작
- **사진으로 분석하기**: MediaPipe FaceLandmarker(478점)를 그때 CDN에서 불러와
  브라우저 안에서 분석한다. 사진은 서버로 전송·저장되지 않는다. 처음 한 번
  라이브러리·모델(약 15MB)을 내려받는다

단일 파일 버전(저장소 루트의 `닮은꼴스타일.html`)은 `python3 lookalike/scripts/build-standalone.py`로
다시 만든다. 코드를 고친 뒤에는 이것도 다시 생성해서 함께 커밋한다.

## 테스트

`lookalike/tests/index.html`을 브라우저에서 연다. `0 failed`여야 한다.
헤드리스: `bash scripts/run-tests.sh lookalike/tests/index.html` (루트에서 실행)

## 동작 방식

```
사진 ─ MediaPipe 478점 ─ features.js ─┐
                                      ├─ 특징 벡터(6축, -1~+1)
퀴즈 답 ─────────── profile.js ───────┘        │
                                 ┌─────────────┼──────────────┐
                           동물상 분류     연예인 매칭       스타일링 규칙
                          (profile.js)    (match.js)      (styling.js)
```

- **특징 벡터 6축**: 얼굴 길이, 턱 폭, 눈꼬리 기울기, 눈 둥글기, 눈 크기, 입술 두께.
  0이 평균이고 ±1이 대략 ±2 표준편차다.
- **기준값(`features.js`의 `BASE`)**: 처음에는 MediaPipe 평균 얼굴 메시(유럽형 3D 모델)에서
  뽑았는데, 위키미디어 사진으로 한국 연예인 15명을 직접 재 보니 얼굴 길이(세로/가로)가
  1.166(메시 1.293), 눈 세로/가로가 0.349(0.266), 눈꼬리가 6.2°(1.2°)로 계속 어긋났다.
  그대로 두면 한국 사용자 대부분이 "둥근 얼굴·동그란 눈·올라간 눈꼬리"로 나온다.
  그래서 어긋난 네 항목의 평균을 그 15명의 평균으로 옮겼다(표는 `features.js` 주석).
  한계: 15명은 대부분 20~30대 연예인(여성 위주, 화장·보정 사진)이라 일반 인구의 평균이
  아니다. 사용자 사진 데이터가 쌓이면 다시 맞춰야 한다.
  (이전 README는 이 어긋남을 촬영 거리 탓으로 설명했지만, 멀리서 찍은 공식 인물사진이
  1.30이 나온 것과 맞지 않아 틀린 설명이었다.)
- **표준편차(sd)는 휴리스틱이다.** 인구 데이터로 검증한 값이 아니다. 너무 가까이서
  찍은 셀카는 얼굴이 길게 나오므로 화면에서 "팔을 쭉 뻗어 찍기"를 안내한다.
- **표정 검사**: MediaPipe가 주는 표정 점수(blendshapes)로 웃는 사진·눈 감은 사진을
  잡아낸다. 웃으면 눈이 가늘고 입술이 얇게 측정돼 여우상 쪽으로 쏠리므로, 그 축은
  값을 임의로 보정하지 않고 "확인 필요"로 표시한다.
- **확인 화면**: 사진 분석 뒤 측정 결과를 퀴즈와 같은 5문항으로 미리 선택해 보여주고,
  사용자가 다른 것만 고친다. 바꾼 문항만 덮어쓰고 나머지는 측정값을 그대로 쓴다.
- **고개 기울기**는 두 눈의 기울기를 평균하면 정확히 상쇄되므로 따로 보정하지 않는다.
  얼굴을 옆으로 돌린 사진(코끝이 가운데서 벗어남)은 경고를 띄운다.
- **연예인 실측 도구** (`lookalike/tools/measure-celebs.html`): 위키미디어 커먼즈에서
  자유 라이선스 사진(CC BY·CC BY-SA·CC0·퍼블릭 도메인, NC·ND 제외)만 검색해 사용자
  사진과 같은 방식으로 잰다. 파일 이름에 그 연예인 이름이 든 사진만 후보로 삼고(얼굴을
  보고 신원을 판단하지 않는다), 정면·무표정·한 명인 사진만 통과시키며, 썸네일을 보고 본인이
  아닌 것은 직접 체크를 풀게 한다. 사진은 저장하지 않고 측정값과 저작자·라이선스·원문
  주소만 `data/celebs-measured.js`로 내보낸다. 연예인당 최대 8장을 평균하고(3장 미만이면
  화면에 경고), 한계값(±1)으로 자르기 전의 원래 측정값(`raw`)을 함께 내보낸다.
  사용법: 인터넷이 되는 PC에서 도구를 열고 [측정 시작] → 썸네일 확인 → [결과 내보내기] →
  나온 내용으로 `data/celebs-measured.js`를 덮어쓴다. 위키미디어는 클라우드 환경 주소에
  요청 제한(429)을 걸어서, 개인 PC에서 돌려야 끝난다.
- **실측 데이터 사용(2026-10)**: `data/celebs-measured.js`에 15명의 `raw` 측정값이 있고, 앱은
  불러올 때 지금 기준값으로 벡터를 계산한다(기준값을 고쳐도 이 파일은 그대로). 여기 있는
  연예인은 인상 태그 대신 실측값으로 비교한다. 스위치는 같은 파일의 `LA.USE_MEASURED`.
  - 빠진 6명(제니·예지·강다니엘·백현·이준기·공유)은 파일 이름에 이름이 든 정면 무표정 사진을
    못 찾아 태그 값을 쓴다. 마동석은 두 사람이 함께 찍힌 사진뿐이라 뺐다.
  - n이 1~2인 연예인(한효주·한예슬·이효리·고아라·강동원·조진웅·김우빈)은 사진 한 장의 오차가 크다.
  - 확인한 것: 기준값을 맞춘 뒤 405가지 얼굴 조합의 1위가 한 명에게 쏠리지 않았다
    (여성 최대 19%, 남성 최대 19%; 태그만 쓸 때 21%, 20%). 기준값을 맞추기 전에는
    이효리(2007년 사진 1장)가 여성 1위의 34%를 차지했었다.
  - 확인하지 못한 것: "닮았다"는 정답이 없어서 정확도가 올랐다고는 말할 수 없다.
    "닮았다고 알려진 쌍"으로 비교해 보는 검증이 남아 있다.
- **알려진 한계**: 실측이 없는 연예인은 사람이 붙인 인상 태그로 비교한다. 자유 라이선스
  사진을 쓰더라도 얼굴 특징 수치를 상업 서비스에 쓰는 것이 초상권(퍼블리시티권) 문제가
  되는지는 별도로 확인해야 한다.
- **일치도(%)** 는 얼굴 인식 점수가 아니라 특징 벡터끼리의 가중 거리를 바꾼 값이다.

## 연예인 데이터 (`data/celebs.js`)

- **연예인 사진은 갖고 있지 않고, 얼굴 인식으로 비교하지도 않는다.** 이름과
  인상 태그(동물상·얼굴형·눈매 등)만 있다. 결과 화면에는 사진 대신 네이버 이미지
  검색 링크를 둔다.
- 태그는 매체·커뮤니티에서 흔히 쓰는 "OO상" 분류와 겉으로 보이는 인상을 사람이
  주관적으로 옮긴 **재미용 값**이다. 확신이 없는 태그는 비워 두고 동물상 원형 값을
  쓴다. 화면 하단에도 이 점을 밝힌다.
- 추가할 때는 `animal`(필수)·`mood`(필수, `styling.js`의 `MOODS` 키)와 아는
  태그만 채우고 테스트를 돌린다 — 검증기(`match.js`의 `validate`)가 잘못된 값과
  id 중복을 잡는다. 성별마다 최소 3명은 있어야 TOP 3가 채워진다.

## 스타일링 규칙 (`js/styling.js`)

| 입력 | 결정하는 것 |
|---|---|
| 얼굴형(5종) × 성별 | 헤어 추천·피할 스타일, 안경·귀걸이/모자 |
| 눈꼬리·눈 모양·입술 | 아이라인·섀도·립 (남성은 눈썹·피부·입술 그루밍) |
| 동물상(7종) × 성별 | 패션 키워드·아이템, 블러셔 위치 |
| 퍼스널컬러 간이 진단 | 컬러 팔레트 6색 (모르면 뉴트럴 팔레트) |
| 닮은꼴 연예인의 무드 | "OO처럼 연출하기" 팁 3개 |

얼굴형별 헤어·안경 공식(둥근형은 세로 라인, 각진형은 곡선 등)처럼 흔히 쓰이는
원칙을 옮긴 것으로, 정답이 아니라 출발점이라는 문구를 결과 화면에 둔다.

## 제약

- npm 의존성 0개, 모든 JS는 클래식 `<script>` (MediaPipe도 IIFE 빌드
  `vision_bundle.js`를 써서 ES 모듈 없이 불러온다)
- MediaPipe 버전은 `js/detector.js`의 `VERSION`에 고정한다
- 서비스워커는 앱 셸만 캐시한다(`la-shell-*`). JS·CSS를 고치면
  `service-worker.js`의 `SHELL_CACHE` 버전을 올려야 설치된 앱에 반영된다
